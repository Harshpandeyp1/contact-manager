# 📇 Contact Manager

A modern, full-stack web application designed to manage your professional and personal connections with zero friction. Built using **React** and **Node.js**.

---

## 🚀 Features

- **Fast & Secure Storage**: Reliable and secure contact data handling.
- **Instant Full-Text Search**: Quickly find any contact within seconds.
- **Clean Grouping**: Organize your most critical network effortlessly.
- **JWT-Backed Access**: Secure authentication protocol for user sessions.

---

## 🛠️ Tech Stack

- **Frontend**: [React](https://github.com/Harshpandeyp1/contact-manager/search?l=javascript) (JavaScript)
- **Backend**: Node.js, Express
- **Database**: MongoDB
